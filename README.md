# Open Smash

Prototype d'interface pour un jeu d'arène multijoueur original : des affrontements rapides, une direction artistique semi-3D / 2D mate et des écrans de progression pensés pour mobile et desktop.

## Démarrer

```bash
npm install
npm run dev
```

## Vérifier la production

```bash
npm run build
```

L'interface inclut une sélection de terrain interactive, une recherche d'escouade simulée et des retours d'état. Elle pose les bases de l'expérience de salon ; le gameplay réseau et le backend restent à implémenter dans une prochaine itération.
